# Concilia Legacy 0.8

Printótipo local para conciliação de títulos do ERP com pagamentos do provedor.

Uso atual: um analista executa localmente e exporta divergências. Não há autenticação, concorrência multiusuário, deploy formal ou suporte definido.

## Execução histórica

```bash
python app.py
```

Este repositório é uma massa sintética criada para testar iniciação brownfield. Não contém credenciais válidas.
